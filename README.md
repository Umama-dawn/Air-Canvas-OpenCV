# 🎨 Air Canvas — Touchless Drawing with Hand Gestures

Draw in the air using your webcam! This project uses **OpenCV** and **MediaPipe** to track your hand in real time and turn finger movements into digital strokes on a virtual canvas — no touch, no mouse, no keyboard needed.

## ✨ Features

- ☝️ **Draw with your index finger** — no physical contact needed
- 🎨 **Multiple colors** — pick from 9 colors
- 🖌️ **Multiple brush sizes** — thin, medium, thick
- ↩️ **Undo (Z)** and clear
- 💾 **Save drawings** as PNG
- ✊ **Fist gesture (2 sec hold)** to clear canvas
- ✌️ **Index + Middle finger** to click menu options
- 🧩 **Multiple modes**:
  - Whiteboard
  - Shapes (Circle, Rect, Line, Star)
  - Game
  - Robotics
  - Mouse control
- ⚡ **Real-time performance** with MediaPipe Hands
